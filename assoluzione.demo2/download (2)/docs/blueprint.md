# **App Name**: Cyclical Guilt

## Core Features:

- Profile Creation: Allow users to create a profile by selecting their language (English or Italian), entering their name/nickname, gender (woman, man, beyond gender binarism), age, and uploading a photo.
- Guilt Assessment: Present a series of increasingly uncomfortable questions to users to build a profile of their guilt, assigning a score based on their answers, reflecting environmental impact, resource extraction, and social costs. The higher the score, the 'more guilty' the user is.
- Data Storage: Store user responses in a database.
- Score Calculation and Display: Calculate and display the user's 'guilt score' and compare it to the average score. Also, show insignificant data multiplied for the world, showing environmental contribution.
- Action Suggestion: After presenting that the guilt is innevitable, suggest practical actions (signing petitions, donating, protesting, boycotting, educating oneself) and note a response if user feels better afterwards.
- The Tribunal Game: Show 'faults' of other participants (taken from their answers) one by one. Present each 'fault' to each user with photo and nickname to decide COLPEVOLE\NON COLPEVOLE. Interaction should affect the user depending on their verdict.
- Personalized Judgement: At the end of the ritualistic tribunal, tell users which data that they shared caused the biggest impact. Use AI as a tool to suggest creative actions (such as personalized donations and petitions to sign) for reducing each person's environmental impact based on what each user reveals during guilt confession questions

## Style Guidelines:

- Primary color: Dark purple (#301934) for a somber and ominous tone.
- Background color: Very dark gray (#121212), nearly black, to enhance the feeling of darkness and unease.
- Accent color: Electric lime green (#32CD32) to simulate glitching or digital errors, providing contrast and catching the user's eye.
- Headline font: 'Space Grotesk' sans-serif for headlines and short amounts of body text; code font: 'Source Code Pro' monospaced, for questions, actions, code and data.
- Use distorted and abstract icons that reflect a glitch aesthetic.
- Create a layout with stark contrasts and disrupted elements to enhance the feeling of unease.
- Incorporate glitching and flickering effects to add to the dystopian and glitchy aesthetic.
